# Source-pinned animation methods considered

This assessment records reusable ideas from read-only GitHub source audits dated 2026-10-08. The pinned files and selected helpers were inspected; upstream tools, models, examples, visual results and benchmark claims were **not** independently run or reproduced. The production instructions remain in this skill's other references. These are original method summaries, not imported code or art.

The skill already required source-faithful art, planted-foot calibration, exact encoded-frame review, and one hash-bound visual acceptance record before this assessment. Adopted methods above clarify decisions inside that workflow. No universal frame count, new service, dependency, approval stage or second QA ledger follows from these sources. Re-check the pinned repositories before any later code or art reuse and honor each license and media restriction; this page does not itself grant reuse rights.
